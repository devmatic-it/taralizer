# Spec: Remove diagram command, embed diagrams in HTML & PDF

## Objective

Remove the `diagram` command and all supporting templates (graphviz, plantuml, mermaid CLI). Instead, make HTML and PDF reports **self-contained** — they render the DFD as an inline SVG via mermaid.js, with no external images needed.

**User story:** As a taralizer user, I want a single report file (HTML or PDF) that contains the complete threat model — including the data flow diagram — without needing to run separate commands or install graphviz/plantuml.

**Success criteria:**
- No `diagram` command exists in the CLI
- HTML report is a single self-contained file with rendered DFD (no `diagram.png`)
- PDF report is a single self-contained file with rendered DFD (no `diagram.png`)
- Markdown report still contains the DFD (embedded mermaid text)
- No external tools required (graphviz, plantuml, mermaid-cli)

## Commands

```
Build:  make build
Test:   go test -v ./pkg/taralizer/... ./cmd/...
Report: ./taralizer report model.yaml --type html --out report
        ./taralizer report model.yaml --type pdf --out report
        ./taralizer report model.yaml --type markdown --out report
```

## Open Questions

1. **Mermaid.js version:** Use latest CDN version (unpkg/jsdelivr)
   → **Decision:** Use latest stable mermaid.js CDN

2. **HTML report rendering:** mermaid.js renders `<pre class="mermaid">` blocks to SVG on page load
   → **Decision:** Embed mermaid.js from CDN + use `mermaid.run()` to render on load

3. **PDF report rendering:** chromedp navigates to the HTML, which triggers mermaid.js rendering → then `PrintToPDF` captures the rendered page
   → **Decision:** Same HTML template as HTML report, chromedp handles the rest

4. **CDN dependency:** HTML report loads mermaid.js from CDN at render time
   → **Decision:** Acceptable — it's a single script tag, mermaid.js is widely cached. PDF reports don't need it (chromedp renders offline).

5. **Offline use case:** What if a user has no internet?
   → **Decision:** Document that HTML reports require internet for mermaid.js. PDF reports are self-contained since chromedp renders during generation.
